Up and running in a minute

Get started

Works on macOS, Linux, and Windows.

1

Paste the install command

Copy the one-liner up top into your terminal. It downloads the whole agent to ~/.nexus/agent and creates a global nexus command.

2

Type nexus and pick a model

On first run it lists top LLMs. Choose one and paste that provider's key (free Gemini keys work great to start).

3

Chat, or go autonomous

Ask anything, or run /do plan my week and draft the emails. Use /cron to make it recur. That's it.

Questions

Good to know

Is it free?

The CLI is free to install and use. You bring your own model key — a free Gemini key from Google AI Studio is enough to get going. You only pay your model provider for what you use.

Which models can I use?

Gemini 2.5 Pro, Anthropic Claude (Sonnet), and OpenAI GPT-4o. Pick one on first run and switch anytime with /model.

Where does my API key go?

Only to ~/.nexus/config.json on your own machine (locked down with file permissions). It's never bundled with the code, pushed to GitHub, or stored in any database.

Can it really book things or send emails?

It prepares them — but anything that spends money or sends a message pauses for your explicit approval. Nexus never completes those actions on its own.

Does it work on Windows?

Yes. Use the PowerShell command on the install tab. macOS and Linux use the curl one-liner.
